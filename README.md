# Conversor de Temperatura

Aplicação web simples para conversão de temperaturas, desenvolvida para demonstrar testes unitários e integração contínua utilizando GitHub Actions.

## Funcionalidades

- Celsius para Fahrenheit
- Fahrenheit para Celsius
- Celsius para Kelvin
- Kelvin para Celsius

## Tecnologias

- HTML
- CSS
- JavaScript
- Vite
- Vitest
- GitHub Actions

## Executando o projeto

Instale as dependências:

```bash
npm install
```

Execute em desenvolvimento:

```bash
npm run dev
```

## Testes

```bash
npm test
```

## Build

```bash
npm run build
```

## Integração Contínua

O projeto utiliza GitHub Actions para executar automaticamente:

1. instalação das dependências
2. testes unitários
3. build da aplicação

O pipeline é executado a cada push ou pull request para a branch `main`.
